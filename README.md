# 진학프로 즉시지원 스크랩 — 운영 매뉴얼

진학프로(jinhakpro.com) 채용정보 페이지에서 "즉시지원" 공고를 자동으로 수집해서 구글 스프레드시트에 기록하고, 신규 공고 알림 메일 / 마감 D-3 알림 메일을 자동 발송하는 시스템입니다.

## 1. 전체 구조

```
[진학프로 API] --(15분마다 자동 실행)--> [Val Town: main.ts] --> [구글 스프레드시트 5개 탭]
                                                |
                                                +--> [Gmail SMTP] --> 담당자 이메일
```

| 구성 요소 | 역할 |
|---|---|
| **GitHub** (`jinhakpro/Apply-list`) | 코드의 원본(소스 오브 트루스)을 보관. 버전 관리 및 변경 이력 확인용. **여기 코드를 고친다고 실제 서비스가 바로 바뀌지 않습니다.** |
| **Val Town** (`jinhakproscrap/apply-scraper`) | 실제로 코드가 15분마다 자동 실행되는 곳(런타임). 이 프로젝트의 `main.ts`가 GitHub의 [scrape.ts](scrape.ts) 최신 내용과 **수동으로 동일하게 맞춰줘야** 합니다 (자동 동기화 아님). |
| **구글 스프레드시트** | 크롤링 결과와 이메일 발송 상태가 저장되는 곳. |

> ⚠️ **중요**: GitHub에 커밋해도 Val Town에는 자동 반영되지 않습니다. [scrape.ts](scrape.ts) 코드를 수정한 뒤에는 반드시 **Val Town `main.ts`에 수동으로 복사/붙여넣기 + Save**까지 해야 실제로 동작이 바뀝니다.

## 2. scrape.ts가 하는 일 (15분마다 순서대로 실행)

### 2-1. 신규 공고 수집
1. 진학프로 API(`/api/applicant/recruit/sub-list?isOnlyOnlineApply=true...`)로 즉시지원 공고 전체 목록 조회
2. "즉시지원 리스트" 시트에 이미 있는 공고ID는 제외하고, 신규 공고만 추림
3. 신규 공고마다 상세 API(`/api/applicant/recruit/recruit-detail/{id}`)를 호출해서 전공/학력/마감일/지역 등 상세 정보 확보
4. 아래 4개 시트에 각각 한 행씩 추가:

| 시트명 | 기록 내용 |
|---|---|
| **즉시지원 리스트** | A:공고ID, B:기관명, C:공고명, D:공고 링크, E:이메일 발송여부(기본 "미발송"), F:마감일, G:D-3 발송여부(기본 "미발송") |
| **광고배너 등록** | 공고ID, 제목(기관명 제거된 공고명), 접수기간, 로고 이미지 URL, 배경색("배너 배경색 DB" 시트 조회), 링크, 배너운영기간 |
| **오카방 메시지** | 공고ID, `[기관명] 공고명`, 카카오톡 오픈채팅용 UTM 링크 |
| **소셜발행** | 공고ID, 기관명, 공고명, 전공1~8, 전공기타, 학력조건, 마감일, 근무지역, D-day, 페이스북용 UTM 링크 |

### 2-2. 신규 공고 알림 이메일 발송 (`checkAndSendEmails`)
- "즉시지원 리스트"에서 E열(이메일 발송여부)이 **"미발송"**인 행을 찾아서
- 같은 공고ID로 연결된 "광고배너 등록" / "오카방 메시지" / "소셜발행" 데이터와, 기관명으로 연결된 "광고배너 계약 여부" 데이터를 모아
- HTML 이메일 1건을 만들어 발송하고, 성공하면 E열을 **"발송완료"**로 변경
- **실패하면 E열이 "미발송"으로 남아 다음 15분 실행 때 자동 재시도됩니다.**

### 2-3. 마감 D-3 알림 이메일 발송 (`sendD3Reminders`)
- "즉시지원 리스트"에서 G열(D-3 발송여부)이 **"미발송"**이고, F열(마감일)이 "오늘 기준 D-3"에 해당하는 행들을 모두 모음
  - D-3 날짜가 주말이면 직전 평일(금요일)로 당겨서 계산
- 대상이 있으면 여러 건을 한 통의 이메일로 묶어서 발송, 성공하면 해당 행들의 G열을 **"발송완료"**로 변경
- 이 로직도 15분마다 실행되므로, "오늘이 발송 예정일인데 아직 미발송"인 첫 실행 때 자동으로 나갑니다.

## 3. Val Town 환경변수 (Env vars)

Val Town 프로젝트(`jinhakproscrap/apply-scraper`)의 왼쪽 메뉴 "Env vars"에 아래 값들이 설정되어 있어야 합니다.

| 변수명 | 필수 여부 | 설명 |
|---|---|---|
| `GOOGLE_SERVICE_ACCOUNT_EMAIL` | 필수 | 구글 서비스 계정 이메일 (스프레드시트에 편집자로 공유되어 있어야 함) |
| `GOOGLE_PRIVATE_KEY` | 필수 | 구글 서비스 계정 private key (PEM 형식, `-----BEGIN PRIVATE KEY-----`부터 끝까지 전체) |
| `GOOGLE_SHEET_ID` | 필수 | 대상 스프레드시트 ID (URL의 `/d/`와 `/edit` 사이 문자열) |
| `GMAIL_USER` | 필수(이메일 발송용) | 발신 Gmail 주소 |
| `GMAIL_APP_PASSWORD` | 필수(이메일 발송용) | Gmail 앱 비밀번호 (16자리, 구글 계정 보안 설정에서 발급) |
| `EMAIL_RECIPIENTS` | 선택 | 신규 공고 알림 수신자, 콤마로 구분. 미설정 시 기본값(`cgh@jinhakapply.com, magi77@jinhakapply.com, yjkim1014@jinhakapply.com, psj@jinhakapply.com`) 사용 |
| `D3_EMAIL_RECIPIENTS` | 선택 | D-3 마감 알림 수신자, 콤마로 구분. 미설정 시 기본값(`cgh@jinhakapply.com`) 사용 |

`GMAIL_USER`/`GMAIL_APP_PASSWORD`가 없으면 시트 기록 작업은 정상 진행되고, 이메일 발송 단계만 로그를 남기고 건너뜁니다.

## 4. 스프레드시트에 미리 있어야 하는 시트(탭)

아래 5개 탭이 정확히 이 이름으로 존재해야 합니다. 없으면 해당 기능이 오류를 냅니다.

- `즉시지원 리스트`
- `광고배너 등록`
- `오카방 메시지`
- `소셜발행` (A1:Q1 헤더가 비어있으면 첫 실행 때 자동으로 채워짐)
- `배너 배경색 DB` (A열: 기관명, B열: 배경색 hex 코드)
- `광고배너 계약 여부` (A열: 기관명, B열: `Y`/`N`) — 이메일 발송 시에만 참조

또한 서비스 계정 이메일(`GOOGLE_SERVICE_ACCOUNT_EMAIL`)이 이 스프레드시트에 **편집자 권한**으로 공유되어 있어야 합니다.

## 5. 실행 주기

Val Town Cron 트리거로 **15분마다(`*/15 * * * *`)** 자동 실행됩니다. (Val Town `main.ts` 화면 우측 상단 "Add trigger"에서 설정/확인 가능)

## 6. 코드 수정 시 체크리스트

1. 로컬 [scrape.ts](scrape.ts) 수정
2. `git add scrape.ts && git commit -m "..." && git push` → GitHub 반영 (변경 이력 보관용)
3. Val Town `main.ts`에 수정된 [scrape.ts](scrape.ts) 전체 내용을 복사해서 붙여넣고 **Save**
4. 필요하면 "Run" 버튼으로 수동 실행해서 정상 동작 확인
5. Val Town 코드 에디터에 뜨는 `'Deno' 이름을 찾을 수 없습니다` 같은 타입 오류는 로컬 에디터가 Deno 타입을 몰라서 뜨는 것으로, Val Town 자체 실행에는 영향 없음 (무시해도 됨)

## 7. 참고자료 (원본 Google Apps Script)

`참고자료/` 폴더에 있는 파일들은 Val Town으로 이전하기 전에 Google Apps Script로 운영하던 원본 코드로, 로직을 포팅할 때 참고용으로 보관 중입니다.

- `crawl.gs.txt` — 크롤링 & 4개 시트 기록 로직 원본
- `email.gs.txt` / `email_template.html` — 신규 공고 알림 이메일 원본
- `D-3 email.gs.txt` — 마감 D-3 알림 이메일 원본
- `figma.gs.txt` — 피그마 플러그인 연동용 API (현재 Val Town에는 미이전 상태)
